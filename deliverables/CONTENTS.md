# Deliverables

Submission-ready CSVs generated from validated experiments, for direct
handoff (e.g. manual Kaggle upload).

## Convention

Each file is named `<experiment_id>_submission.csv` and matches
`data/sample_submission.csv`'s schema exactly (`id`, `addicted_label`,
same row count and row order). Generation is reproducible via the script
that produced it, referenced below.

## Files

| File | Experiment | Generated by | CV mean ROC AUC | Public LB |
|---|---|---|---|---|
| `E001_submission.csv` | E001 (Logistic Regression baseline) | `python -m src.generate_submission` | 0.91149 (std 0.00081) | 0.91358 |

`E001_submission.csv` was produced by refitting the E001 pipeline
(`src/preprocessing.py` + `LogisticRegression(max_iter=1000,
random_state=42)`) on the full `data/train.csv`, then predicting
probabilities on `data/test.csv`. Cross-validation in
`notebooks/02_baseline.ipynb` is for scoring only — the submission itself
uses a model fit on all available training rows, which is standard
practice and not the same fitted model as any individual CV fold.
